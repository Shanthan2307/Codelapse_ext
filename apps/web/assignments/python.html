1. Overview

You will write a small Python program with two functions: one that returns a string reversed, and one that counts its vowels. Python could reverse a string for you in one line, so this assignment asks you not to use that shortcut and to build the reversed string yourself with a loop. That way you practise the ideas the shortcut hides: indexing, loops that count down, and the fact that Python strings cannot be changed in place.

You will write it in VS Code while the CodeLapse extension records how you work. When you submit, you will answer four short questions about your own work and your own code.

What you will practise

  • Indexing into a string (text[i]), len, and loops with for and range.
  • Why strings are immutable, and how to build a new string (or a list of characters) instead.
  • Writing functions that return a value, and running code only when the file is run as a program.
  • Testing your own code on ordinary and unusual inputs.

2. What to build

Write everything in one file, reverse.py. Use only plain Python (no imports are needed).

def reverse(text: str) -> str

  • Returns a new string with the characters of text in reverse order. It must not print anything.
  • Must build the result with a loop of your own: for example by going through the string from the end, or by swapping characters in a list.
  • Must work for any string, including the empty string "" and a string of one character.

def count_vowels(text: str) -> int

  • Returns how many vowels the string contains. The vowels are a e i o u, in either case (A E I O U count too).
  • y is not a vowel for this assignment. Spaces, digits and punctuation are not vowels.

Running it as a program

  • At the bottom, under if __name__ == "__main__":, put a test word in a variable (for example "codelapse"), call both functions on it, and print the reversed word and the vowel count.
Not allowed in reverse Slicing that reverses (text[::-1] or any slice with a negative step), reversed(), list.reverse(), sorted() tricks, recursion instead of a loop, or any import or library that reverses for you. Allowed: for and while loops, range, len, indexing like text[i], lists, append, and "".join(...) on a list you built yourself.

5. Hints

Read one hint at a time and try it yourself before moving on to the next. They start general and get more specific.

  1. Getting started
    A string is a sequence: text[0] is the first character and text[len(text) - 1] is the last. Indexing past the end raises IndexError.
  2. Strings can't be changed
    Python strings are immutable: text[0] = "x" is an error. So reverse cannot change text; it has to build a new string and return it. Two common ways: start from an empty string and add characters to it, or turn the text into a list of characters, rearrange the list, then join it back with "".join(...).
  3. Which order to visit the characters
    If you visit the characters from the last to the first, adding each one to the end of your result gives the reversed string. Alternatively, visit them first to last and put each new character at the front of your result. Try both on paper with "abc".
  4. Counting down with range
    range(start, stop, step) can count down when step is negative, for example range(5, 0, -1) gives 5, 4, 3, 2, 1. The stop value is never included. Work out which start and stop make the last index you visit be 0, and check it with "ab" and "".
  5. The list-and-swap way
    Like in C: put the characters in a list, keep one index at the start and one at the end, swap, and move both towards the middle. Stop at the middle; going further swaps everything back.
  6. Counting vowels
    Go through the characters and count the ones that are vowels. ch in "aeiou" is True when ch is one of those letters (a set such as {"a", "e", "i", "o", "u"} works too). To include capitals, compare a lower-case version of each character: ch.lower() (or lower-case the whole text once).
  7. Return, don't print
    Both functions should return their result. The printing belongs in the if __name__ == "__main__": block. A function that prints and returns None looks right on screen but fails as soon as anything else uses it.

6. Test your program

  • Run python3 reverse.py in the VS Code terminal after every change (on Windows the command may be py reverse.py or python reverse.py).
  • Compare with the table, and try the edge cases by changing the test word.
  • Let Python check for you with assert lines in the __main__ block. An assert stays silent when the condition is true and stops with an AssertionError when it is false:
assert reverse("ab") == "ba"
assert count_vowels("rhythm") == 0

Self-check before you submit

  • Runs with python3 reverse.py without errors.
  • reverse uses a loop of your own: no [::-1], no reversed(), no .reverse().
  • Correct for "", "a", "ab", "abc" and "Hello, World!".
  • count_vowels counts capital vowels and does not count y.
  • Both functions return their result, with the names and parameters exactly as specified.
  • The printing happens under if __name__ == "__main__":.
  • You can explain, in your own words, how your loop visits the characters and why it starts and stops where it does.

9. The four questions

Right after you submit, the page shows four short questions about your own work: two about things you did while working (for example an error you fixed, or something you rewrote), and two about specific lines of your code. Every student gets different questions.

  • You have one hour from submitting to answer, and you can submit your answers once. A timer shows the time left; your draft is kept if you refresh the page.
  • Write a few sentences each, in your own words. Spelling and grammar do not matter.
  • Explain why, not just what: why the loop starts and stops where it does, why you chose that approach, what an error message told you.
  • Be specific: mention the actual line, variable, error or change. "It works" says much less than "the loop starts at the last index because …".
  • If you are not sure, say what you think and why. An honest partial answer is better than a vague one.
