# Export your recording

When your code is finished:

1. Run **CodeLapse: Export Assignment Bundle (.codelapse)**.
2. If CodeLapse is still recording, it asks to stop first, so the file is complete.
3. Choose where to save the file, for example next to your assignment folder.

You get one file such as `reverse.codelapse`. It holds every session recorded in the folder and a fingerprint of each file in it. It contains your code, so share it only by uploading it to your course.
