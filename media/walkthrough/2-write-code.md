# Write and build your code as usual

There is nothing extra to do while you work.

- **Typing:** CodeLapse keeps snapshots of your files as they change, so your work can be replayed.
- **Building and running:** commands such as `gcc -Wall -o reverse reverse.c` and `./reverse` are recorded with whether they succeeded, when you run them in VS Code's terminal (bash, zsh, fish or PowerShell) or as a VS Code task.
- **Breaks:** close VS Code whenever you like. The session is saved, and a new one starts next time.

To see what has been recorded so far, run **CodeLapse: Show Session Report & Analytics** or click the status bar item.
