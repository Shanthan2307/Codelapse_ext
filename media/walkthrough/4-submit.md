# Submit it with your code

1. Run **CodeLapse: Open Submission Page**. The first time, VS Code asks for the submission page address your instructor gave you, then opens it in your browser.
2. Choose your name.
3. Drop in your `.codelapse` file and your code files (for example `reverse.c`).
4. Click **Submit Assignment**.

To change the address later, open **Settings** and search for *CodeLapse: Submission Url*.

If the upload is refused, the page says why (for example a missing file) and you can try again.
